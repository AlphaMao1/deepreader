# Domain Docs

This repo currently uses a single-context domain model.

## Files

- Glossary: `CONTEXT.md`
- ADRs: `docs/adr/` if and when architectural decisions need to be recorded
- Historical PRDs: `docs/prd/archive/`
- Current PRDs: `docs/prd/current/`
- Local issue drafts and recovery docs: `docs/issues/`

## Consumer Rules

- Read `CONTEXT.md` before writing PRDs, issues, or architecture proposals.
- Treat archived PRDs as evidence, not as the current source of truth.
- When the user resolves a domain term or product decision, update `CONTEXT.md`.
- Create ADRs only for hard-to-reverse, surprising trade-offs.
